About {{ SITE_NAME }}

{{ SITE_NAME }} is a database of wordlists for the Trans-New Guinea language family and its neighbours, built to study the prehistory of New Guinea with the comparative method and computational phylogenetics.

The data

  • Wordlists are transcribed from sources. Every lexical item records its source, and each source page has a BibTeX download.
  • Meanings are standardised to a common list of words, so forms can be compared across languages. The original gloss is kept where it differs.
  • Classifications and families follow Glottolog and are updated with each Glottolog release.
  • Locations on the maps are attached through each language's ISO 639-3 code.
  • Cognate sets group related forms where they have been coded.

Using the data

The data are licensed under a Creative Commons Attribution 4.0 International License. Please cite the database (see right) together with the original sources you use. Languages, sources, words and lexical items are also available through the JSON API.

Corrections

Found an error in a form, a gloss or a classification? Please open an issue on GitHub, with a link to the page and, where possible, a reference.
